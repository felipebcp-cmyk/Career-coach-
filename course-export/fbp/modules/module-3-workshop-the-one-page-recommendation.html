Build a real recommendation using the Module 3 toolkit, end to end.

Steps

  1. Choose a live decision in your organisation that finance should have a view on (an investment, a renewal, a cost programme, a price change).
  2. Write the one-sentence problem statement: decision, deadline, context. Confirm it with the decision-maker if you can.
  3. Develop three options including a priced 'do nothing'. Agree (or propose) the decision criteria before scoring them.
  4. Run a five-minute pre-mortem on your preferred option and fold the top two risks and mitigations into the page.
  5. Write the one-page recommendation using the Lesson 3 skeleton, and identify who you'd socialise it with one-to-one before any formal meeting.

Deliverable

Paste your one-sentence problem statement and one-sentence recommendation below.
